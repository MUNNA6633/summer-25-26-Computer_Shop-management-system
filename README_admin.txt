COMPUTER SHOP MANAGEMENT SYSTEM - ADMIN PANEL

1. Copy this whole folder to:
   C:\xampp\htdocs\computer_shop_admin

2. Start Apache and MySQL from XAMPP.

3. Open http://localhost/phpmyadmin
   Import: sql/setup.sql

4. Open:
   http://localhost/computer_shop_admin/admin/login.php

5. Demo admin login:
   Email: admin@computershop.com
   Password: admin123

The existing CSS from the provided CSS ZIP is kept in /css. The new admin.css is added for the admin panel.

IMPORTANT:
- This is a student project/demo setup. Change the demo password before any real deployment.
- Database credentials are in config/database.php. XAMPP's default MySQL user is root with an empty password.
